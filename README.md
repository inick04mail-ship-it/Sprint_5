# Автотесты для Stellar Burgers

Сайт: https://stellarburgers.education-services.ru/

Проверки

1. Регистрация  
   - успешная регистрация нового пользователя;  
   - ошибка при регистрации с коротким паролем.

2. Вход  
   - вход по кнопке «Войти в аккаунт» на главной;  
   - вход через кнопку «Личный кабинет»;  
   - вход через ссылку «Войти» в форме регистрации;  
   - вход через ссылку «Войти» в форме восстановления пароля.

3. Личный кабинет и навигация  
   - переход в личный кабинет для авторизованного пользователя;  
   - переход из личного кабинета в конструктор по кнопке «Конструктор»;  
   - переход из личного кабинета в конструктор по клику на логотип;  
   - выход из аккаунта по кнопке «Выход».

4. Конструктор  
   - по умолчанию активна вкладка «Булки»;  
   - можно переключаться на вкладки «Соусы» и «Начинки» (параметризованный тест с тремя сценариями).

Проект:

- tests/test_registration.py — тесты регистрации.  
- tests/test_login.py — тесты входа разными способами.  
- tests/test_navigation.py — переходы в личный кабинет, выход, возврат в конструктор.  
- tests/test_construction.py — параметризованный тест для вкладок конструктора («Булки», «Соусы», «Начинки»).  

С учетом замечания ревью отредактированы и добавлены новые:

- locators.py — локаторы элементов (кнопки, поля, ссылки, вкладки конструктора).  
- data_generators.py— генерация уникальных email и паролей.  
- data.py — тестовые данные (существующий пользователь, базовое имя, минимальная длина пароля).  
- helpers.py — вспомогательные функции для переходов между страницами и работы с формами.  
- urls.py — базовый URL приложения.  
- conftest.py — настройка Selenium WebDriver и общие фикстуры (в том числе логин существующего пользователя).
