# Автотесты для Stellar Burgers


Сайт: https://stellarburgers.education-services.ru/

Проверки

1. Регистрация:
   - успешная регистрация нового пользователя;
   - ошибка при регистрации с коротким паролем.

2. Вход:
   - вход по кнопке «Войти в аккаунт» на главной;
   - вход через кнопку «Личный кабинет»;
   - вход через ссылку «Войти» в форме регистрации;
   - вход через ссылку «Войти» в форме восстановления пароля.

3. Личный кабинет и навигация:
   - переход в личный кабинет;
   - переход из личного кабинета в конструктор по кнопке «Конструктор»;
   - переход из личного кабинета в конструктор по клику на логотип;
   - выход из аккаунта по кнопке «Выход».

4. Конструктор:
   - вкладки «Булки», «Соусы», «Начинки»;
   - по умолчанию активна вкладка «Булки»;
   - можно переключаться на «Соусы» и «Начинки».

 Файлы

- tests/test_registration.py — тесты регистрации.
- tests/test_login.py — тесты входа.
- tests/test_navigation.py — переходы в личный кабинет, выход, возврат в конструктор.
- tests/test_construction.py — проверки раздела «Конструктор».
- locators.py — все локаторы элементов (кнопки, поля, ссылки).
- data_generators.py — генерация уникальных email и паролей.
- conftest.py — настройка Selenium WebDriver и общие фикстуры.
